# Учебный менеджер

**Автор:** Драгомарецкий Д.Ю., группа 24ПИ2

## Тема и сценарий

Учебный менеджер помогает студенту вести учебные задания по курсам. Пользователь добавляет задание, указывает курс и дедлайн, меняет статус и находит просроченные записи.

## Стек

React, TypeScript, Vite. Node.js 22.20.0

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```

## Адреса страниц

- `/` — редирект на список заданий
- `/assignments` — список с фильтром по статусу
- `/assignments/:id` — подробности задания
- `/assignments/new` — создание задания
- `/assignments/:id/edit` — редактирование задания
- любой другой адрес — страница «не найдена»

## Справочник курсов

Курсы загружаются по HTTP из файла `frontend/public/demo/courses.json` (адрес `/demo/courses.json`). Запрос выполняет `frontend/src/services/courses.ts`, загрузкой управляет хук `useCourses`. Ответ проверяется во время выполнения: статус HTTP, структура JSON, уникальность id. В задании хранится id курса, в форме показывается название. Пока справочник недоступен или курс не выбран, сохранить задание нельзя. В форме есть состояния загрузки, ошибки и пустого справочника, а также кнопка «Повторить», которая не стирает введённые поля.

## Что работает сейчас

- Создание, редактирование и удаление заданий (с подтверждением).
- Выбор курса из справочника, загруженного по HTTP.
- Фильтр по статусу со сбросом.
- Проверка обязательных полей и предметное правило (для выполненного задания нужно описание результата).

**Важно:** основные записи хранятся только в памяти открытого приложения. После обновления страницы возвращаются пять демонстрационных заданий. Справочник курсов читается из файла и не изменяется приложением.

## Текущие ограничения

Supabase, авторизация и Node API появятся в следующих лабораторных работах. В карточке и подробностях пока показывается код курса, а не название.
