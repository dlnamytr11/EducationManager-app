# Учебный менеджер

**Автор:** Драгомарецкий Д.Ю., группа 24ПИ2

## Тема и сценарий

Учебный менеджер помогает студенту вести учебные задания по курсам. Пользователь добавляет задание, указывает курс и дедлайн, меняет статус и находит просроченные записи.

## Стек

React, TypeScript, Vite. Node.js 22.20.0

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```

## Адреса страниц

- `/` — редирект на список заданий
- `/assignments` — список с фильтром по статусу
- `/assignments/:id` — подробности задания
- `/assignments/new` — создание задания
- `/assignments/:id/edit` — редактирование задания
- любой другой адрес — страница «не найдена»

## Справочник курсов

Курсы хранятся в таблице `courses` в Supabase (PostgreSQL) и читаются форме через `frontend/src/services/courses.ts` и хук `useCourses`. Ответ проверяется во время выполнения. В задании хранится id курса, в форме показывается название. Кнопка «Обновить справочник» перезагружает список без потери введённых полей.

## Настройка Supabase

1. Создайте проект Supabase.
2. В SQL Editor выполните `supabase/migrations/202611160001_initial_schema.sql`, затем `supabase/seed.sql`.
3. В `frontend` создайте `.env.local` по образцу `.env.example` и заполните переменные:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
4. Перезапустите `npm run dev`.

Secret key, service_role и пароль базы во frontend и в репозиторий не добавляются.

## Что работает сейчас

- Создание, редактирование и удаление заданий (с подтверждением).
- Выбор курса из справочника в Supabase.
- Фильтр по статусу со сбросом.

**Важно:** основные записи (задания) по-прежнему хранятся только в памяти открытого приложения. После обновления страницы возвращаются пять демонстрационных заданий. Постоянным стал только справочник курсов. Личная таблица `assignments` создана, но закрыта от браузера до ЛР 6 (авторизация).

## Текущие ограничения

Supabase, авторизация и Node API появятся в следующих лабораторных работах. В карточке и подробностях пока показывается код курса, а не название.
