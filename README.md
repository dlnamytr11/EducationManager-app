# Учебный менеджер

**Автор:** Драгомарецкий Д.Ю., группа 24ПИ2

## Тема и сценарий

Учебный менеджер помогает студенту вести учебные задания по курсам. Пользователь добавляет задание, указывает курс и дедлайн, меняет статус и находит просроченные записи.

## Стек

React, TypeScript, Vite. Node.js 22.20.0

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```

## Справочник курсов

Курсы хранятся в таблице `courses` в Supabase (PostgreSQL) и читаются форме через `frontend/src/services/courses.ts` и хук `useCourses`. Ответ проверяется во время выполнения. В задании хранится id курса, в форме показывается название. Кнопка «Обновить справочник» перезагружает список без потери введённых полей.

## Что работает сейчас

- Регистрация и вход по email и паролю (Supabase Auth), выход.
- Личные страницы доступны только после входа.
- Создание, просмотр, редактирование и удаление заданий. Данные хранятся в Supabase и сохраняются после перезагрузки и повторного входа.
- Каждый пользователь видит только свои задания.
- Выбор курса из справочника `courses` в Supabase.
- Фильтр заданий по статусу со сбросом.

## Авторизация и доступ

Вход выполняется через Supabase Auth. Маршруты защищены компонентом `RequireAuth`, но настоящую защиту данных обеспечивает база: у таблицы `assignments` включён RLS и четыре политики (select, insert, update, delete) с условием `owner_id = auth.uid()`. Справочник `courses` доступен для чтения всем, изменять его нельзя. Гость к `assignments` доступа не имеет.

## Адреса страниц

- `/auth` — вход и регистрация
- `/assignments` — список заданий (после входа)
- `/assignments/new` — создание задания
- `/assignments/:id` — подробности задания
- `/assignments/:id/edit` — редактирование задания
- любой другой адрес — страница «не найдена»

## Настройка Supabase

1. Создайте проект Supabase.
2. В SQL Editor по порядку выполните:
   - `supabase/migrations/202611160001_initial_schema.sql`
   - `supabase/migrations/202611230001_assignments_owner_policies.sql`
   - `supabase/seed.sql`
3. В Authentication → URL Configuration укажите Site URL и Redirect URL `http://localhost:5173` (свой порт).
4. В `frontend` создайте `.env.local` по образцу `.env.example` и заполните:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
5. `cd frontend`, `npm ci`, `npm run dev`.

Пароли, токены, secret key и `service_role` в репозиторий не добавляются.

## Текущие ограничения

Связанные сущности и поиск по нескольким параметрам появятся в следующих работах. В карточке и подробностях пока показывается код курса, а не его название. Если включено подтверждение email, после регистрации нужно перейти по ссылке из письма.
