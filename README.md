# Учебный менеджер

**Автор:** Драгомарецкий Д.Ю., группа 24ПИ2

## Тема и сценарий

Учебный менеджер помогает студенту вести учебные задания по курсам. Пользователь добавляет задание, указывает курс и дедлайн, меняет статус и находит просроченные записи.

## Стек

React, TypeScript, Vite. Node.js 22.20.0

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```

## Адреса страниц

- `/` — редирект на список заданий
- `/assignments` — список заданий (с фильтром по статусу)
- `/assignments/:id` — подробности задания по id
- `/assignments/new` — создание нового задания
- `/assignments/:id/edit` — редактирование задания
- любой другой адрес — страница «не найдена»

## Что работает сейчас

- Общий layout с навигацией и пояснением о временном хранении данных.
- Список заданий с фильтром по статусу («Все», «Не начато», «В процессе», «Выполнено») и кнопкой сброса фильтра.
- Создание нового задания через форму с проверкой обязательных полей и предметным правилом (для выполненного задания требуется описание результата).
- Редактирование существующего задания той же формой, с сохранением исходного id.
- Удаление задания с подтверждением через диалоговое окно.
- Страница подробностей задания, определяемая по адресу (работает при прямом открытии и обновлении страницы).
- Страница «не найдено» для неизвестных адресов и отдельное сообщение для несуществующей записи.
- Проверка типов TypeScript и production-сборка.

**Важно:** данные (создание, изменение, удаление) хранятся только в памяти открытого приложения. После обновления страницы (F5) все изменения теряются и восстанавливаются пять демонстрационных записей из `frontend/src/data/assignments.ts`. Постоянное хранение появится позже, вместе с Supabase.
