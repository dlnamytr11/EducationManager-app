# Ход работы

## ЛР 1. Старт проекта на React и TypeScript

Создан проект `frontend` на Vite (шаблон react-ts). Стартовый экран заменён на экран приложения «Учебный менеджер»: название, описание и заглушка списка заданий. Проект опубликован в Git-репозитории.

### Как проверить

1. `cd frontend`, затем `npm ci`.
2. `npm run dev` и открыть адрес из терминала: виден экран «Учебный менеджер», счётчика и логотипов Vite нет.
3. Сузить окно или включить мобильный режим (320–375 px): горизонтальной прокрутки нет.
4. `npm run build`: проверка типов и сборка проходят без ошибок.
5. `npm run preview` и открыть адрес: готовая сборка показывает тот же экран.
