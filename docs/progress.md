# Ход работы

## ЛР 1. Старт проекта на React и TypeScript

Создан проект `frontend` на Vite (шаблон react-ts). Стартовый экран заменён на экран приложения «Учебный менеджер»: название, описание и заглушка списка заданий. Проект опубликован в Git-репозитории.

### Как проверить

1. `cd frontend`, затем `npm ci`.
2. `npm run dev` и открыть адрес из терминала: виден экран «Учебный менеджер», счётчика и логотипов Vite нет.
3. Сузить окно или включить мобильный режим (320–375 px): горизонтальной прокрутки нет.
4. `npm run build`: проверка типов и сборка проходят без ошибок.
5. `npm run preview` и открыть адрес: готовая сборка показывает тот же экран.

## ЛР 2. Страницы приложения и навигация

Установлен React Router. Добавлены типизированный массив заданий (5 демонстрационных записей), повторно используемый компонент карточки `AssignmentCard`, страницы списка и подробностей, заглушка создания, страница «не найдено» и общий layout с навигацией. Подключены маршруты через `BrowserRouter`, `Routes` и `Route`. Запись определяется по параметру адреса `:id` через `useParams`.

### Как проверить

1. `npm run dev`, открыть `/` — виден список из пяти заданий.
2. Открыть две разные карточки, сравнить содержимое.
3. Скопировать адрес одной карточки, открыть в новой вкладке и обновить страницу — задание отображается корректно.
4. Перейти по ссылке «Создать» — видна заглушка и общая навигация.
5. Открыть `/unknown` — видна страница «не найдена».
6. Открыть `/assignments/missing` — видно сообщение об отсутствующей записи.
7. Временно очистить массив данных — проверить сообщение «Заданий пока нет», затем вернуть записи обратно.
8. Проверить клавиши «назад»/«вперёд», узкий экран (без горизонтальной прокрутки) и переходы по Tab/Enter.
9. `npm run build` и `npm run preview` — сборка проходит без ошибок, прямое открытие карточки работает в preview.
